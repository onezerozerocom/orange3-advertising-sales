# 광고비와 매출 사이의 관계 알아보기

오렌지3로 광고비(TV·Radio·Newspaper)와 매출(Sales)의 관계를 분석하는 학습지 웹앱입니다.

`index.html` 파일 하나로 동작합니다. 크롬이나 엣지로 열거나, 깃허브 페이지 같은 곳에 올려 주소로 나눠 주면 됩니다.

## 학습지 구성

- 데이터셋 내려받기 · 살펴보기 (advertising.csv 다운로드, 데이터프레임 표, 속성 설명)
- **과제 1 · 단순 선형 회귀 분석 (통계적)**: CH 1 ~ CH 3
- **과제 2 · 다중 선형 회귀 분석 (통계적)**: CH 4
- **과제 3 · 단순 선형 회귀 분석 (기계학습 기반)**: CH 5 (학습·평가 데이터로 나누기), CH 6 (새로운 데이터 `new_markets.csv`로 예측)

CH마다 **오렌지3에서 이렇게 해 보세요** 안내(사진 포함)가 있고, CH 3~6 끝에는 오렌지3 화면 **캡처 붙여넣기** 칸이 있습니다.

## 학생은 이렇게 씁니다

1. 맨 위에 **학번·이름**을 적습니다.
2. CH 1~6을 풉니다. 적은 내용은 **탭이 열려 있는 동안만** 저장됩니다. 새로고침해도 남아 있지만, 탭이나 브라우저를 닫으면 지워집니다.
   - 적은 답이 있는 채로 창을 닫으려 하면 브라우저가 "사이트에서 나가시겠습니까?"처럼 한 번 묻습니다.
3. CH 3~6 끝의 **캡처 칸**에 오렌지3 작업 화면을 붙여 넣습니다.
   - `Win` + `Shift` + `S`로 화면을 캡처 → 캡처 칸을 클릭 → `Ctrl` + `V`
   - 이미지 파일을 캡처 칸에 끌어다 놓아도 됩니다. 큰 캡처는 자동으로 줄여서(가로·세로 최대 1600px) 저장합니다.

입력칸에 맞지 않는 값을 넣으면 정답을 알려 주지 않고 형식만 점검해 줍니다. (예: 오차 지표가 0보다 작음, R²가 1보다 큼)
